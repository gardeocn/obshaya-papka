# Общее файловое хранилище

Небольшое приложение для Windows: компьютер-хозяин запускает веб-хранилище, а друзья открывают его в браузере через одну сеть Radmin VPN. Интерфейс управления — отдельное WPF-окно; отдельные серверы или пакеты устанавливать не нужно.

## Возможности

- Загрузка нескольких файлов и папок, выбор папки назначения, прогресс и примерное оставшееся время.
- Просмотр каталогов, скачивание, удаление, миниатюры изображений и просмотр поддерживаемых фото/видео.
- Ограничение объёма хранилища, пароль для доступа и список недавно подключавшихся устройств.
- Журнал событий для отладки и сохранение настроек приложения.

## Требования

- Windows 10/11 и Windows PowerShell 5.1.
- На компьютере-хозяине и устройствах друзей должна быть одна и та же сеть Radmin VPN.
- Друзьям достаточно современного браузера.

## Быстрый запуск

1. Скачайте проект целиком (Code → Download ZIP) и распакуйте архив.
2. Запустите `Start-ShareManager.cmd`.
3. В приложении выберите адрес Radmin VPN, папку и лимит, задайте пароль и нажмите «Запустить хранилище».
4. Отправьте друзьям ссылку и пароль. Они должны подключиться к той же сети Radmin VPN.

Не перемещайте изображения из `assets`: они используются окном управления и темой сайта.

## Безопасность и ограничения

Сервер предназначен для использования внутри доверенной сети Radmin VPN. Веб-соединение использует HTTP, а не HTTPS, поэтому пароль и передаваемые файлы не защищены шифрованием на транспортном уровне. Не открывайте порт сервера в интернет и не используйте его в публичных или недоверенных сетях.

При публикации проекта на GitHub не добавляйте журналы, настройки приложения, пароль, IP-адреса устройств или содержимое папки хранилища. `.gitignore` исключает стандартные журналы и пользовательские данные.

---

Отдельное окно Windows для запуска общего хранилища и обмена файлами через Radmin VPN. Дополнительные программы устанавливать не нужно: используется Windows PowerShell. Фоновая фотография программы хранится в `assets\share-manager-background.jpg`; оставьте её рядом с программой.

## Запуск

Дважды щёлкните [Start-ShareManager.cmd](./Start-ShareManager.cmd). В окне программы:

1. Подключитесь к сети Radmin VPN. Нажмите «Обновить список адресов» и выберите VPN-адрес.
2. Укажите папку и лимит места в гигабайтах.
3. Придумайте пароль и нажмите «Запустить хранилище».
4. Нажмите «Копировать» и отправьте ссылку вместе с паролем друзьям.

Друзья должны подключиться к той же сети Radmin VPN, открыть ссылку в браузере и ввести пароль. Имя пользователя можно указать любое. Справа отображаются адреса устройств, которые недавно обращались к хранилищу. Устройство считается подключённым, если оно обращалось к серверу в последние две минуты.

Кнопка «Остановить» выключает сервер. Закрытие окна также останавливает его.

## Если сервер не запускается

При первом запуске Windows может потребоваться разрешение для выбранного VPN-адреса. Программа запишет в журнал команду `netsh http add urlacl`. Откройте PowerShell **от имени администратора**, выполните указанную команду и снова нажмите «Запустить хранилище».

Если друзья не могут открыть ссылку, разрешите входящие подключения TCP-порта 8765 в брандмауэре Windows. Ограничьте правило частной сетью/Radmin VPN. Не настраивайте проброс порта на роутере и не открывайте сервер в интернет.

## Файлы и отладка

- Файлы сохраняются в выбранной папке; установленный лимит действует на её содержимое.
- Загруженные файлы не удаляются при остановке или повторном запуске приложения.
- Папка, лимит и Radmin VPN-адрес сохраняются автоматически и восстанавливаются при следующем запуске.
- Пароль сохраняется только если включить «Запомнить пароль на этом компьютере». Он хранится зашифрованным средствами Windows для текущего пользователя.
- Файлы с совпадающими именами не перезаписываются.
- Чтобы выбрать, куда друзья будут загружать файлы, откройте нужную папку в списке и нажмите «Загружать сюда». Выбранный путь показан над областью загрузки; обычные файлы, вставленные фото/видео и выбранная папка будут загружаться в это место.
- На странице загрузки можно нажать Ctrl+V, чтобы добавить скопированные фото и видео из буфера обмена; затем нажмите «Загрузить». Кнопка «Выбрать папку» загружает файлы всей папки, сохраняя вложенные папки; также можно перетащить файлы или папки в область загрузки.
- Можно добавлять несколько файлов одной партией: одновременно передаются до четырёх файлов, у каждого свой индикатор прогресса и оценка оставшегося времени. Оценка появляется после начала передачи данных и обновляется во время загрузки. Если имя занято, новый файл автоматически получает суффикс, например `фото (1).jpg`.
- В списке отображаются папки и файлы текущего каталога. Нажмите на папку, чтобы открыть её; путь сверху позволяет вернуться к родительской папке или в корень. Поддерживаются русские имена, пробелы и вложенные папки; их структура сохраняется при загрузке. В списке файлов отображаются миниатюры изображений и кадры поддерживаемых видео; по нажатию открывается просмотр. Друзья также могут загружать, скачивать и удалять файлы. Доступны только файлы в выбранной папке хранилища; для видео поддерживаются переход и перемотка.
- На сайте доступны три темы — светлая, тёмная и «сюся.» с прикреплённым фото на фоне; переключатель циклически меняет их, выбор запоминается в браузере. Файл темы хранится в `assets\susya-theme.jpg`, не перемещайте его отдельно от приложения.
- События сервера записываются в `share-debug.log`; ошибки запуска PowerShell — в `share-errors.log`.

Дополнительный запуск без графического окна возможен командой:

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\share_server.ps1 -MaxGB 10 -DebugMode
```
